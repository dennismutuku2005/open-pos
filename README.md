**Open POS** is a professional-grade retail management suite designed for high-growth operations.  
It features a high-performance **POS Terminal** with real-time M-Pesa integration and distraction-free workflows.  
The system includes advanced **Sales Analytics** with interactive bar graphs, pie charts, and growth tracking.  
Full **CRUD capabilities** allow for seamless management of transactions, inventory, and staff records.  
Built with a premium **Blue-First** design system and shimmering skeletons for an instant-feel user experience.
